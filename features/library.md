# 最近入库

独立的 `媒体库` 菜单已经并入 [概览](./dashboard.md)。

当前控制台里，最近入库的电影和剧集直接放在 `概览` 底部。

## 现在应该看哪一页

### 想看最近上了什么

去 [概览](./dashboard.md)，在页面底部切换 `电影` 或 `剧集`。

### 想复制服务器地址再去播放器里看

也去 [概览](./dashboard.md)。服务器入口和最近入库在同一页。

### 想调整 Emby 里显示哪些库

那不是浏览页。去 [账号中心](./account-center.md) 的 `媒体库偏好`，或在 Bot 里发 `/libraries`。

## 这页还保留做什么

旧文档和旧链接仍可能写成“媒体库”。
现在把它当成入口说明：内容已经回到概览，设置已经回到账号中心。
